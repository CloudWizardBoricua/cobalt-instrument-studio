## 0.1.0 — Fall 2026

Initial engineering build is publicly hosted on Netlify and GitHub Pages. The workflow-created GitHub Release remains pending.

- Added one seeded model driving six synchronized instruments and bounded chart history.
- Added normal ramp, coolant overheat, and communication loss replays.
- Added validated thresholds, debounce, hysteresis, acknowledgments, deduplicated alerts, and recovery events.
- Added responsive dashboard, diagnostics, settings, day/night appearance, metric display, and local settings persistence.
- Added explicitly simulated CSV exports and an engineering evidence panel.
- Added automated model/browser checks, engineering documentation, and static hosting builds.
- Verified remote CI and published Netlify and GitHub Pages deployments; retained the tag-triggered workflow for the pending release.
