# Cobalt Instrument Studio 0.1.0

_Developed by Daren Diaz_ · [GitHub repository](https://github.com/CloudWizardBoricua/cobalt-instrument-studio)

An original, browser-only industrial instrumentation simulator with six synchronized instruments, reproducible operating scenarios, diagnostic state transitions, and downloadable engineering documentation.

Telemetry is simulated. No hardware interface, live equipment access, backend, safety control, authentication, certification, or production guarantee is provided.

This version includes bounded charts and event history, acknowledgment and recovery behavior, validated settings, day/night display, metric/imperial presentation, and local CSV export. See the engineering report for recorded validation results and the roadmap for potential future work.

Public host availability must be checked separately. This file prepares release notes; its existence does not mean a release has been published.
